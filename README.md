# Feldbuch

Handy-App (PWA) für Feldgrenzen und Feldtagebuch. Alle Daten bleiben auf dem Gerät (IndexedDB); Sicherung über „Backup speichern".

- Import: Shapefile (.zip mit .shp/.shx/.dbf/.prj), KML/KMZ, GeoJSON, GPX
- Export: Backup (JSON inkl. Fotos), Tagebuch als CSV, Feldgrenzen als GeoJSON
- Offline: App-Dateien und besuchte Kartenkacheln werden zwischengespeichert

Läuft als statische Seite über GitHub Pages. GPS braucht HTTPS.
